# Cognitive Companion Premium UX Map

The premium experience should feel attentive without becoming invasive.

- Beginner flow: robot becomes quietly attentive when a session starts.
- Focus flow: robot holds a neutral/focus expression while a question is active.
- Review flow: robot gives a gentle review reminder when due count is high.
- Streak flow: robot celebrates small positive streaks without spam.
- Struggle flow: robot encourages after wrong answers and can suggest a break when risk is high.
- Session-complete flow: robot marks completion with a calm or premium expression.
- Disconnected flow: robot returns to neutral or calm error.

The robot never reveals answers, never speaks content-specific private info, and does not move unless a later safety-reviewed phase explicitly enables motion.
