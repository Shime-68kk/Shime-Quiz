# BIG-UPDATE-6 StudyRoom Subject Spaces Release Summary

Decision status: BIG_UPDATE_6_STUDYROOM_SUBJECT_SPACES_DEFINED

## Summary

BIG-UPDATE-6 adds subject-aware StudyRoom summaries, local forgetting alert models, subject navigation for mobile-friendly UX, coarse robot-safe subject summaries, subject-space backup metadata helpers, notification preference modeling, docs, validator, and tests.

## Boundaries

- Local-first: yes.
- Cloud/backend/network added: no.
- Push notification backend added: no.
- Browser notification permission requested: no.
- Real robot bridge added: no.
- Raw question/answer sent to robot: no.
- SM2/FSRS behavior changed: no.
- FSRS default changed: no.

## Recommendation

Keep this as a local subject-space UX/model phase. A future phase can wire real local device notifications only after permission UX and backup compatibility are reviewed.
