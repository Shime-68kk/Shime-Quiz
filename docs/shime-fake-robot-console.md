# Shime Fake Robot Console

## Purpose

The fake robot console simulates a Robot Shime expression endpoint in memory. It is not a real device and does not connect to hardware.

## Meaning

- Current face means display expression label.
- Current light means LED pattern label.
- Current sound means sound cue label.
- Motion lock must always show locked.
- Transcript rows are bounded and in-memory only.

## Boundaries

- No real transport.
- No robot send.
- No motion.
- No persistence.
- No raw quiz content.
