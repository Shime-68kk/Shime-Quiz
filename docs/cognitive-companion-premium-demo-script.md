# Cognitive Companion Premium Demo Script

The user sees a companion that becomes attentive when study starts, stays focused during questions, encourages after wrong answers, celebrates streaks, calms down on errors, and returns neutral when transport disconnects.

The robot would only receive safe command families such as `focus`, `encourage`, `celebrate`, `due_review`, `session_complete`, `error_signal`, or `neutral`.

The app never sends prompt text, answer text, explanations, typed answers, imported documents, full history, backups, credentials, camera data, microphone data, or identity.

The safety governor blocks motion, unsafe transport, repeated celebration spam, and sensitive payloads. This feels intelligent because it reacts to timing and coarse learning state, not private content.
