# Cognitive Companion Control Center

Date: 2026-06-27 09:21:43 +07

## Purpose

The Companion Control Center is a dev-only foundation for reviewing future premium robot companion behavior without sending commands to any device.

## Current Safety Boundaries

- Dev-only panel inside Settings.
- Fake scenario mode remains explicit.
- Live Device Bridge mode remains observe-only.
- No StudyRoom changes.
- No Device Bridge runtime changes.
- No ESP32 firmware changes.
- No robot command sending.
- No AI/cloud/backend/auth.
- No telemetry.
- No storage or persistence.

## Modes

Fake scenario mode replays redacted/coarse fixtures for testing companion decisions.

Live observe-only mode watches already-redacted Device Bridge events after the developer explicitly enables it.

## Command Preview

The planned command preview is dry-run only. It derives display rows from sanitized transcript entries and marks every row as `dryRunOnly: true` and `sendStatus: "not_sent"`.

No send button, connect button, WebSocket send, ESP32 call, or robot motion path exists in this phase.

## Session Insight

The session insight summary is generated by local deterministic rules from sanitized transcript rows. It is not AI and does not call any external service. It does not mention quiz content.

## Not Production AI

This phase is a control-center foundation, not production AI behavior. Future premium UI can reuse these display patterns only if privacy, no-send, and explicit-gate boundaries remain intact.
