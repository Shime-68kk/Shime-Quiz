# Shime Expression Protocol Pipeline

Phase 39X pipeline:

`Shime Fusion -> Expression Plan -> Expression Envelope -> Fake Transcript -> ESP32 Log-only Preview`

The pipeline is dev-only, dry-run only, and evidence-only. It does not mount new UI, does not connect to a robot, does not mutate Device Bridge, does not change StudyRoom, and does not change scheduler, storage, import, backup, or firmware behavior.

The app remains canonical. The safety governor wins over expression mapping. Robot-side planning receives only safe expression envelopes and never raw learning content.
