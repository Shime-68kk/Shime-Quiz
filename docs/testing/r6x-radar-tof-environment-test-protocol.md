# R6X Radar + ToF Environment Test Protocol

Use this when hardware arrives. The current phase is simulation only.

Principles:
- radar does not replace ToF
- radar handles wide presence/off-axis
- ToF handles front/near confirmation
- no camera/mic/cloud
- no real bridge
- no hardware access in this phase
- target: ESP32-S3 + HLK-LD2410/LD2410B + VL53L0X
- fault-tolerant for non-expert users
- future hardware phase will validate real radar logs

Protocol cases are generated by:

```sh
node scripts/run-radar-tof-sensing-scenarios.js --protocol
```
