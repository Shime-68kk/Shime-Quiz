# Cognitive Companion AI Roadmap

No AI provider is implemented in Phase 20X.

## Stages

1. Deterministic local policy engine.
2. Dataset logging with privacy-safe coarse features only.
3. Offline model training from coarse features.
4. Tiny local model or rule table export.
5. Optional local AI planner research.
6. Optional cloud AI only behind explicit opt-in, never default.

Future AI must never receive raw quiz content, imported documents, full history, backups, credentials, camera frames, audio recordings, or biometric identity.
