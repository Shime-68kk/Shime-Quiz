# Shime Ecosystem Vision

Shime Robot is the public product face. Shime Quiz is the local-first learning brain.

The product thesis is that Shime Robot makes invisible memory dynamics visible and emotionally meaningful. FSRS-derived memory signals remain canonical in the app; the robot receives only redacted/coarse capsules.

No cloud is required. Optional future AI must be local or privacy-preserving and capsule-limited.
