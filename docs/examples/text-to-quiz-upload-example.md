# Ví dụ file .md để tạo quiz nháp

Người dùng có thể lưu nội dung dưới dạng `.txt` hoặc `.md`, sau đó chọn file trong trang Thư viện. Ứng dụng đọc file ngay trong trình duyệt, tạo bản nháp câu hỏi và yêu cầu xem trước trước khi lưu.

Môn: Mạng máy tính
Chủ đề: OSI

Câu hỏi: Application layer thuộc mô hình nào?
A. OSI
B. TCP/IP
C. HTTP
D. DNS
Đáp án: A
Giải thích: Application là tầng trong mô hình OSI.

Flashcard:
Mặt trước: Private IP 10.0.0.0/8 là gì?
Mặt sau: Một dải địa chỉ IPv4 private.

Câu hỏi ngắn: TCP hoạt động ở tầng nào?
Đáp án: Transport
