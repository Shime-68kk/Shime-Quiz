# Ví dụ nhập quiz từ văn bản/Markdown

Người dùng có thể dán nội dung này vào mục **Tạo quiz từ văn bản/Markdown** trong trang Thư viện.
Ứng dụng sẽ tạo bản nháp câu hỏi để xem lại trước khi lưu cục bộ.

## Trắc nghiệm

Môn: Mạng máy tính
Chủ đề: OSI

Câu hỏi: Application layer thuộc mô hình nào?
A. OSI
B. TCP/IP
C. HTTP
D. DNS
Đáp án: A
Giải thích: Application là tầng trong mô hình OSI.

## Flashcard

Flashcard:
Mặt trước: Private IP 10.0.0.0/8 là gì?
Mặt sau: Một dải địa chỉ IPv4 private.

## Câu hỏi ngắn

Câu hỏi ngắn: TCP hoạt động ở tầng nào?
Đáp án: Transport

## Ghi chú Markdown có cấu trúc

# Mạng máy tính
## OSI
- Application layer là tầng 7.
- TCP hoạt động ở tầng Transport.
