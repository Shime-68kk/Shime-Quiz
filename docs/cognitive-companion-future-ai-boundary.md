# Cognitive Companion Future AI Boundary

The deterministic kernel is the default and remains the source of authority.

## Current Phase

- No AI API.
- No provider SDK.
- No cloud calls.
- No telemetry.
- No raw quiz content.

## Future Rules

- AI may only consume coarse companion context.
- No prompt text, answer text, explanations, user answers, imported documents, identity, biometric data, camera frames, microphone recordings, full history, backups, or credentials.
- Offline/local model research comes before any cloud research.
- Cloud AI is future optional opt-in only, never default.
- Outputs must be explainable with reason codes.
- Safety governor always has final authority.
- AI cannot directly command robot motion.
