# Shime Robot Expression Mapping

## Purpose

This document explains how Shime fusion outputs map to future expression-only robot actions.

## Mapping Principles

- High due pressure maps to a calm review nudge.
- Low retrievability maps to memory-risk support.
- Repeated lapse or high recovery need maps to gentle encouragement.
- Stability gain is preferred over one-correct celebration because it reflects durable memory progress.
- Session completion can be acknowledged softly.
- Transport unsafe maps to reconnect hint or neutral presence.
- Privacy unsafe maps to calm error or no-op.
- Quiet/protect-rest mode maps to no-op or neutral presence.
- Classroom safe mode lowers intensity and avoids sound.

## Boundaries

The mapper emits expression plans only. It does not send commands, connect to transport, mutate schedules, unlock motion, or consume raw content.

## Privacy Model

Expression mapping uses coarse buckets and fusion summaries only. It does not need prompts, answers, explanations, user responses, source data, settings, history, backup data, media, or biometric data.
