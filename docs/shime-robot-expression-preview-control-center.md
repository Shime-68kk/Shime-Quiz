# Shime Robot Expression Preview Control Center

## Purpose

Section D now includes a dev-only Robot Shime expression preview. It lets a tester see the Shime fusion summary, expression plan labels, fake robot state, capability preview, safety status, privacy status, and why nothing was sent.

## Current Safe Scope

- Explicit-click only.
- Requires a prior Shime fusion result.
- Dry-run only.
- No real robot send.
- No real transport.
- No motion.
- No raw data.
- No persistence.

## What The UI Shows

- Biểu cảm dự kiến.
- Mặt/hiển thị.
- Đèn.
- Âm thanh.
- Khóa chuyển động.
- Trạng thái an toàn.
- Trạng thái riêng tư.
- dry-run / không gửi.
- Lý do chính.
- Capability preview.
- Fake robot console.

## Remaining Risks

This is still only a preview. Real device integration needs a separate safety phase.
