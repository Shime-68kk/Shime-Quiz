# Shime Robot Capability Preview

## Purpose

The capability preview renders the future Robot Shime handshake as safe labels. It is schema-only and does not negotiate with a real device.

## Shows

- Display, LED, sound, presence, Wi-Fi, BLE, SoftAP, and USB dev support.
- Motion support and motion lock.
- Capsule protocol version.
- Expression contract version.
- Privacy mode.
- Safety mode.
- dry-run / not sent.

## Does Not Show

- Credentials.
- SSID.
- Password.
- IP address.
- Token.
- Secret.
- Any real connection status.
